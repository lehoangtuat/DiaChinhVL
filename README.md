# DiaChinhVL – công cụ địa chính cho MicroStation V8i

Kho này dùng để **cập nhật từ xa** cho DiaChinhVL.

- `version.txt` – dòng 1: số phiên bản (vd `1.1`), các dòng sau: ghi chú thay đổi.
- `files.txt` – danh sách module sẽ nạp.
- `modules/` – mã nguồn từng module (dán vào code pane VBA).

Người dùng: trong menu DiaChinhVL chọn **Trợ giúp → Kiểm tra cập nhật**.

Phát hành bản mới: thay file trong `modules/`, tăng số trong `version.txt`, đưa lên GitHub.
